3. Description de la conception

Cette section est entièrement remplie — tu n'as rien à modifier.

Stack technique

Frontend : HTML5 CSS3 JavaScript Bootstrap 5
Backend : Python 3 Flask Flask-SQLAlchemy Flask-Login Flask-SocketIO
Base de données : MySQL 8 SQLAlchemy ORM
Sécurité : bcrypt Sessions sécurisées
Versionnement : Git GitHub

Les 3 modules de l'application

Module 1 — Comptes & Profils
  • Inscription avec vérification email/téléphone unique
  • Connexion sécurisée (mot de passe hashé avec bcrypt)
  • Modification du profil à tout moment
  • Gestion des compétences maîtrisées et des lacunes
  • Gestion des disponibilités horaires
  • Réinitialisation du mot de passe
Module 2 — Matching
  • Publication d'offres et demandes de mentorat
  • Algorithme de matching automatique
  • Score basé sur : compétences communes + horaires + filière
  • Affichage des résultats avec score de compatibilité
  • Acceptation ou refus d'une correspondance
  • Recherche par matière ou horaire
Module 3 — Messagerie
  • Messagerie en temps réel (Flask-SocketIO)
  • Conversation créée automatiquement après un matching accepté
  • Historique des conversations conservé
  • Notifications en temps réel pour les nouveaux messages

Structure de la base de données — 10 tables

Table Module Rôle dans l'application Colonnes principales
users1Tous les comptes utilisateursid, nom, prenom, email, telephone, mot_de_passe, filiere, niveau, photo, bio
competences1Liste des matières disponibles (Algo, Python, Réseaux…)id, nom, categorie
user_competences1Compétences de chaque utilisateur : ce qu'il maîtrise ou veut amélioreruser_id, competence_id, type (maitrise / a_ameliorer)
disponibilites1Créneaux horaires disponibles par utilisateurid, user_id, jour, heure_debut, heure_fin
offres2Offres et demandes de mentorat publiéesid, user_id, type (offre/demande), format_seance, description, statut
offre_competences2Matières ciblées par chaque offre ou demandeoffre_id, competence_id
matchings2Paires mentor-mentoré proposées par l'algorithmeid, mentor_id, mentore_id, score (0-100), statut
conversations3Espace de messagerie lié à un matching acceptéid, matching_id, date_creation
messages3Messages individuels dans les conversationsid, conversation_id, expediteur_id, contenu, date_envoi, lu
notifications3Alertes en temps réel pour les utilisateursid, user_id, contenu, type, lu, date_creation

Pour installer et faire fonctionner l'application, la machine doit avoir :

  • Python 3.10 ou supérieur
  • MySQL 8.0 ou supérieur
  • Git
  • Un navigateur web récent (Chrome, Firefox, Edge)

📝 Fonctionnalité 1 — Créer un compte (S'inscrire)

Pour commencer à utiliser IFRI_MentorLink, chaque étudiant doit créer un compte :

  1. Ouvrir l'application dans le navigateur
  2. Cliquer sur le bouton "S'inscrire" sur la page d'accueil
  3. Remplir le formulaire :
    • Nom et prénom
    • Adresse email (doit être unique)
    • Numéro de téléphone (doit être unique)
    • Mot de passe (minimum 8 caractères)
    • Filière et niveau d'études
  4. Sélectionner ses compétences maîtrisées (ce que tu peux enseigner)
  5. Sélectionner ses lacunes (ce dans quoi tu as besoin d'aide)
  6. Cliquer sur "Créer mon compte"

🔗 Fonctionnalité 4 — Trouver un mentor ou offrir du mentorat
  1. Cliquer sur "Trouver un mentor" ou "Proposer du mentorat" dans le menu
  2. Publier une offre ou une demande en précisant :

    • Ses disponibilités

💬 Fonctionnalité 5 — Envoyer et recevoir des messages
  1. Après qu'un matching est accepté, une conversation est créée automatiquement
