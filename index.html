1. Présentation du groupe

Description du projet

IFRI_MentorLink, c'est une application web qu'on a développée pour répondre à un problème concret qu'on vit tous les jours à l'IFRI : quand tu bloques sur une matière, c'est difficile de savoir rapidement qui peut t'aider, et à l'inverse, si tu maîtrises bien un domaine, tu ne sais pas forcément qui en a besoin. L'idée, c'est d'automatiser cette mise en relation. Chaque étudiant crée un profil avec ses compétences maîtrisées, ses lacunes et ses disponibilités, et l'algorithme calcule automatiquement un score de compatibilité pour proposer les meilleures correspondances entre mentors et mentorés. Une messagerie en temps réel est intégrée directement dans l'application pour que les deux parties puissent s'organiser sans avoir à sortir de la plateforme. L'ensemble du projet est structuré en trois modules : gestion des comptes et profils, algorithme de mise en correspondance, et messagerie instantanée.

Application Factory Pattern
On a utilisé ce pattern Flask pour éviter les imports circulaires entre les modules. app.py crée l'application via une fonction create_app() qui initialise les extensions (SQLAlchemy, SocketIO, etc.) et enregistre les blueprints. Chaque module a son propre blueprint avec son préfixe d'URL.
Blueprints Flask
Chaque module est isolé dans son propre Blueprint : /auth, /profil, /offres, /matching, /messagerie. Ça simplifie le travail en équipe — chaque développeur ne touche qu'à son fichier de routes.

Module 1 — Comptes & Profils

Module 3 — Messagerie

Algorithme de matching — Comment le score est calculé

L'algorithme compare le profil de l'utilisateur connecté avec tous les autres utilisateurs de la plateforme et calcule un score de compatibilité sur 100 points selon trois critères pondérés :

60 pts
Compétences communes

Nombre de matières qui se croisent entre ce que l'utilisateur maîtrise et ce que l'autre veut améliorer (et vice versa). C'est le critère le plus important.

30 pts
Disponibilités compatibles

Nombre de créneaux horaires en commun entre les deux profils. Un mentor et un mentoré qui ne sont jamais disponibles en même temps, ça ne sert à rien.

10 pts
Proximité de filière

Si les deux étudiants sont dans la même filière (SI, IA, GL, IM...), le score est bonifié. Les problèmes de cours sont souvent communs entre étudiants d'une même filière.

Exemple : Alice (SI, maîtrise Algo et Python, disponible lundi et mercredi) cherche quelqu'un pour la ML. Bob (IA, maîtrise ML, disponible lundi et vendredi) cherche de l'aide en Algo. Score Alice→Bob : 60 (ML en commun) + 15 (lundi en commun sur 2 dispos) + 0 (filières différentes) = 75/100.

Choix techniques — Pourquoi on a choisi ça

Flask plutôt que Django Flask est minimaliste — il n'impose rien. On a pu construire exactement la structure qu'on voulait, module par module. Django aurait été trop lourd pour 10 jours de projet avec une équipe de L1.
MySQL plutôt que SQLite Le cahier des charges déconseille explicitement SQLite. MySQL 8 est plus robuste, gère mieux la concurrence et correspond mieux à une vraie application multi-utilisateurs.
Flask-SocketIO pour la messagerie La messagerie devait être en temps réel, c'était une exigence obligatoire validée en session d'encadrement. SocketIO utilise les WebSockets pour que les messages arrivent instantanément sans recharger la page.
bcrypt pour les mots de passe bcrypt est un hash à sens unique — il est impossible de retrouver le mot de passe original depuis le hash stocké en base. Chaque hash est unique grâce au salt intégré, ce qui protège contre les attaques par rainbow table.

4. Instructions de déploiement local

Avant de commencer, assurez-vous d'avoir ces outils installés sur votre machine :

  • Git — pour cloner le dépôt (git-scm.com)

5. Manuel d'utilisation

Ce guide décrit comment utiliser les fonctionnalités de l'application, de la création de compte jusqu'à l'échange de messages en temps réel.

📝 1 — Créer un compte

Pour commencer à utiliser IFRI_MentorLink, chaque étudiant doit créer un compte. L'inscription prend environ 2 minutes.

  1. Ouvrir l'application dans le navigateur : http://127.0.0.1:5000
  2. Cliquer sur "S'inscrire" sur la page d'accueil
  3. Remplir le formulaire :
    • Nom et prénom
    • Adresse email (doit être unique)
    • Numéro de téléphone (doit être unique)
    • Mot de passe (minimum 8 caractères)
    • Filière et niveau d'études
  4. Cocher les compétences maîtrisées (ce que vous pouvez enseigner)
  5. Cocher les lacunes (les matières où vous avez besoin d'aide)
  6. Définir vos disponibilités horaires (jours et créneaux)
  7. Cliquer sur "Créer mon compte"
Après inscription, vous êtes automatiquement connecté et redirigé vers le tableau de bord.
🔑 2 — Se connecter
  1. Aller sur http://127.0.0.1:5000/auth/connexion
  2. Saisir votre adresse email ou votre numéro de téléphone
  3. Saisir votre mot de passe
  4. Cliquer sur "Connexion"

Un message de bienvenue s'affiche en haut de la page après connexion réussie. Si vos identifiants sont incorrects, un message d'erreur s'affiche et vous pouvez réessayer.

🏠 3 — Explorer le tableau de bord (matching)

Le tableau de bord est la page principale. Il présente deux sections calculées automatiquement par l'algorithme :

  • Mentors recommandés (section bleue) — Les étudiants dont les compétences correspondent à vos lacunes, avec leur score de compatibilité affiché
  • Qui je peux mentorer (section verte) — Les étudiants dont les lacunes correspondent à vos compétences

Sur chaque carte, le score (ex: 75/100) indique le niveau de compatibilité calculé par l'algorithme. Plus le score est élevé, mieux c'est. Pour démarrer un mentorat :

  1. Repérer un profil qui vous intéresse
  2. Cliquer sur "Contacter" (ou "Proposer mon aide")
  3. La conversation s'ouvre automatiquement — vous pouvez commencer à écrire
👤 4 — Gérer son profil

Vous pouvez modifier votre profil à tout moment. Les modifications sont répercutées immédiatement sur l'algorithme de matching.

  1. Cliquer sur votre prénom dans la barre de navigation en haut
  2. Cliquer sur "Modifier le profil"
  3. Modifier vos informations (nom, bio, filière, niveau)
  4. Cocher ou décocher vos compétences et lacunes
  5. Ajouter, modifier ou supprimer vos créneaux de disponibilité
  6. Cliquer sur "Enregistrer les modifications"
📋 5 — Publier et gérer des offres de mentorat

En plus du matching automatique, vous pouvez publier des offres ou des demandes de mentorat manuelles.

  1. Cliquer sur "Offres & Demandes" dans la barre de navigation
  2. Cliquer sur "Nouvelle offre"
  3. Choisir le type : "Je propose du mentorat" ou "Je cherche un mentor"
  4. Sélectionner les matières concernées
  5. Choisir le format : présentiel, en ligne, ou les deux
  6. Ajouter une description (facultatif)
  7. Cliquer sur "Publier"

Vos offres apparaissent dans la liste et peuvent être modifiées ou supprimées à tout moment via les boutons correspondants.

💬 6 — Envoyer et recevoir des messages

La messagerie est en temps réel — les messages arrivent instantanément sans recharger la page.

  1. Cliquer sur "Messages" dans la barre de navigation
  2. Sélectionner une conversation dans la liste à gauche
  3. Taper votre message dans la zone de texte en bas
  4. Appuyer sur Entrée ou cliquer sur l'icône ✈️ pour envoyer

Pour tester le temps réel : ouvrez deux navigateurs (ou deux onglets en navigation privée) avec des comptes différents, ouvrez la même conversation sur les deux — les messages s'affichent en direct de part et d'autre.
